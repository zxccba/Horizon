### [Report: New gTLD Domains Have High Scam Rates](https://simonwillison.net/2026/Sep/6/the-purpose-of-dns-is-to-spread-scams/) ⭐️ 7.0/10

Simon Willison highlights Terence Eden&\#x27;s blog post on DNS abuse, based on an Interisle report. The report states that 85 million new gTLD registrations were made in 2025, and 8.5 million of those were added to blocklists by May 2025. Interisle estimates a 10% abuse rate as the floor, with the real figure likely closer to 20%, meaning about one in five newly registered gTLD domains are scams. Eden describes this as a crisis, and notes that ICANN has been discussing the problem for years. Willison expresses surprise at the scale, pointing readers to the original report and commentary via Andrew Campling.

rss · Simon Willison · Sep 6, 14:40

**「Background」** The Domain Name System \(DNS\) translates human-readable domain names into IP addresses, and generic top-level domains \(gTLDs\) are categories such as .com, .net, and newer ones overseen by ICANN. Cybercriminals frequently register domains for phishing, malware distribution, and scams, so security organizations maintain blocklists of known malicious domains. Interisle Consulting Group periodically measures the use of these blocklists to estimate the scale of DNS abuse.

**「Impact」** Security practitioners and domain registries face increased pressure to treat newly registered gTLD domains as high-risk and to accelerate abuse detection and takedown processes.

### [Sliding Window Attention for Pretrained Hugging Face LLMs at Inference](https://www.reddit.com/r/MachineLearning/comments/1w8repz/applying_sliding_window_attention_to_pretrained/) ⭐️ 7.0/10

A developer introduced a practical, inference-time Sliding Window Attention \(SWA\) layer for pretrained Hugging Face causal LLMs that requires no model modification or retraining. The implementation maintains a bounded KV cache made of attention sinks and a recent sliding window, using ring-buffer storage, attention-sink retention, streaming prefill, chunked attention masking, and autoregressive decoding. Benchmarking on Qwen2.5-7B reported KV-cache memory reductions from roughly 923 MB to 3.5 MB at a 16K context, from about 1.84 GB to 3.5 MB at 32K, and from an out-of-memory failure at 64K to 3.5 MB with SWA-64. The same setup also reduced time-per-output-token \(TPOT\) from about 38.4 ms to 30.5 ms at 16K context. The author notes a key trade-off: tasks requiring information far outside the active window can degrade, and the project is shared on GitHub to gather feedback on architectures, failure cases, and Hugging Face workflow integration.

reddit · r/MachineLearning · /u/ahsaor8 · Sep 6, 09:23

**「Background」** Causal large language models cache the key and value tensors for every previous token so each new token can attend to the full history, making cache memory grow linearly with context length. Sliding window attention instead restricts each token to attend only to a bounded recent window, often while also retaining early “attention sink” tokens, which caps memory use. This project applies that mechanism purely at inference time to already-pretrained models, rather than requiring models to be trained or fine-tuned with SWA from the start.

**「Impact」** Developers running Hugging Face LLMs with very long contexts could use this inference-only layer to keep KV-cache memory extremely small and run contexts that previously caused out-of-memory failures, as demonstrated on Qwen2.5-7B. The practical benefit is conditional, however, because accuracy can drop when the correct answer depends on information outside the active sliding window.

The drug was developed jointly by Westlake University, Westlake Laboratory, and Westlake Pharmaceutical \(Hangzhou\) Co., Ltd. It is described as China&\#x27;s first AI-assisted original drug, taking only three and a half years from initial discovery to completed clinical trials. This milestone illustrates the practical application of artificial intelligence in pharmaceutical research and development. The shortened development cycle is notably faster than traditional drug development timelines, though the approval remains conditional.

**「Background」** AI-assisted drug discovery uses machine learning algorithms to accelerate tasks such as identifying drug targets, screening molecular candidates, and optimizing lead compounds. Conditional approval is an expedited regulatory pathway that allows a drug to reach the market before full clinical confirmation, subject to post-marketing obligations.
